## Contenido

Diez programas sueltos para practicar lo de los temas 1 y 2: variables, tipos de datos, `input()`, conversiones, operadores (aritméticos, relacionales y lógicos), `//` y `%`, y f-strings. No se usan `if`, bucles, listas ni funciones propias porque todavía no los vimos.

1. `programa_01_ficha.py` - Prog. N°1 - Ficha personal
2. `programa_02_compra.py` - Prog. N°2 - Presupuesto de una compra
3. `programa_03_temperatura.py` - Prog. N°3 - Conversor de temperatura
4. `programa_04_tiempo.py` - Prog. N°4 - Conversor de tiempo
5. `programa_05_nomina.py` - Prog. N°5 - Nómina de un trabajador
6. `programa_06_operaciones.py` - Prog. N°6 - Operaciones con dos números
7. `programa_07_rectangulo.py` - Prog. N°7 - Datos de un rectángulo
8. `programa_08_reparto.py` - Prog. N°8 - Reparto de entradas
9. `programa_09_acceso.py` - Prog. N°9 - Comparador de acceso
10. `programa_10_ticket.py` - Prog. N°10 - Ticket de tienda informática

## Ejecución

Abrir una terminal dentro de la carpeta `actividad_10_programas` y escribir:

```
python programa_01_ficha.py
```

Para los demás es lo mismo, solo cambia el nombre del archivo. El programa va pidiendo los datos por consola y hay que darle a Enter después de cada uno.
